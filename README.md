# PetDeek 🐾 · 手机版（Android）

> ⚠️ **这个仓库是安卓版** ✗ —— 桌面上那个（无边框小窗口 / 托盘 / 开机自启）在
> [`Gezi46/Gezi46-pet-seek`](https://github.com/Gezi46/Gezi46-pet-seek) ✓。
> 下面几节的骨架是从那份 README 继承来的 ✓，**桌面专属的东西（鼠标操作、托盘、自启动、
> `启动桌宠.bat`、`%APPDATA%` 路径）在手机上不存在** ✗ —— 手机上的玩法看「跑起来」「怎么玩」
> 「手机版和桌面版不一样的地方」三节 ✓。

一个会浮在你手机上的蓝发女仆。

她自己待着时会站着晃、隔一会儿眨一下眼；可以摸、可以跟她聊天、她会记住你说过的话；
你退到别的 App 之后她会缩成一颗**悬浮球**跟着你 —— 点一下接着聊、**双击就截一张屏**看。

用 **Godot 4.7** 做的，模型是 Blockbench 的。

---

## 跑起来

这是**手机版** ✓ —— 它得装到手机上跑 ✓（不是双击就开 ✗）。

1. **装 Godot 4.7 + Android 导出模板**（编辑器里「管理导出模板…」装一次 ✓），
   再设好 `ANDROID_HOME` / `JAVA_HOME`（用的是 JDK 17 ✓）
2. 手机上打开 **USB 调试**、插上电脑，`adb devices` 里能看到它
3. 导出并安装：

```powershell
godot --headless --path . --export-debug "Android" "dist/pet-android.apk"
adb install -r dist/pet-android.apk
```

> ⚠️ **第一次会先导入资源**（那个 3D 模型要转一遍 ✓），导入完成前导出会报一堆
> `referenced non-existent resource` —— **那不是代码问题** ✓。`.godot/` 是导入缓存，不进版本库 ✓。
>
> 只想看代码结构：用 Godot 直接打开这个文件夹也行 ✓ —— 但**按 F5 跑出来的是个桌面窗口** ✗，
> 手机特有的那套（触摸 / 悬浮球 / 截屏）不会出现 ✓。

### 想让她能聊天

不配也能用，只是她只会说本地台词。要真聊天，**右键她 → 「AI 服务设置」**，填一个后端地址和 key。

支持任何 OpenAI 兼容接口：

| 后端 | 地址 | 说明 |
| --- | --- | --- |
| DeepSeek 官方 API | `https://api.deepseek.com` | 要付费 key |
| 本地网页版代理 | `http://127.0.0.1:8520/v1` | 自建，不需要官方 key |

> 密钥存进 `%APPDATA%\...\桌宠\pet_secret.dat`（AES-256 加密），配置文件里**永远是空的**，
> 面板里默认也**遮着显示** —— 截图不怕漏。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| **点她** | 摸头：随机害羞 / 挥手 / 做表情，并说一句 |
| **双击她** | **截一张当前屏幕给她看** ✓（会弹系统那个「允许截屏吗」✓ —— 点一次「开始」就行 ✓） |
| **按住拖** | 把她挪到屏幕上任意位置 |
| 右下角 **「＋」** | 从相册挑一张给她看 |
| 右上角 **⚙** | 设置页：后端 / 模型 / 密钥 / 看图模型 / 用哪个摄像头 / 多久看一眼 / 主动说话 / 悬浮球 / 导出日志 |
| **底部对话框** | 打字聊天；她回话时气泡会流式冒字，旁边还有 3 句「你可能接着说」的候选 |
| **退到别的 App** | 她缩成一颗**悬浮球**浮在别的 App 上 ✓ —— **点一下**=弹出小聊天框 ✓ **双击**=截屏 ✓ **按住拖**=挪球 ✓ |

闲置时她会站着微微晃、隔几秒眨一下眼；**退到后台她就不动了** ✗（引擎被系统暂停 —— 这是安卓的规矩 ✓，见「手机版和桌面版不一样的地方」✓）。

## 出问题了

**设置页（右上角 ⚙）→「导出日志」** ✓ —— 手机的「下载」里会出现一份 `PetDeek-日志-<时间>.zip`：
里面是「系统信息.txt」（引擎 / 系统 / 她当前的设置）+「程序日志.txt」+「引擎日志.txt」。
**密钥和记忆不在里面**（导出前会逐行隐去 ✓），**可以直接发给别人看** ✓。

| 症状 | 先翻哪一份 |
| --- | --- |
| 起不来 / 一开就退 | 「引擎日志.txt」—— 脚本报错、资源加载失败都在里面 |
| 她不理人（但还会动） | 「程序日志.txt」里 `ERR [聊天]` 那几行：连不上 / 401 / 超时，原因都写着 |
| 退到别的 App 她就不动了 | **这不是故障** ✓ —— 安卓会暂停后台 App 的引擎 ✓（见下面那节 ✓），你回来看她时她接着跟你说 |
| 想整个重置（她会忘了你） | 系统设置 → 应用 → PetDeek → **清除数据** ✓（记忆 / 设置 / 密钥都在那儿 ✓） |

## 手机版和桌面版不一样的地方

| | 桌面版 | 手机版 |
| --- | --- | --- |
| 她怎么待着 | 在屏幕上自己散步、撞边折返 | **站着微微晃 + 眨眼**（手机上不散步 ✓） |
| 退到后台 | 一直在（她本来就"住"在桌面上） | **引擎被系统暂停** ✗ —— 她会缩成一颗悬浮球陪你 ✓，但**不会自己思考** ✓（实测过：前台服务按住进程也救不活主循环 ✓） |
| 偷看屏幕 | 能截屏偷看 | **只有摄像头** ✓（安卓不给"截屏偷看"那条 ✓）；想给她看东西：**双击她**截屏 ✓ 或右下角「＋」发图 ✓ |
| 导出日志 | 右键「导出日志…」→ 桌面 | 设置页「导出日志」→ 手机的**「下载」** ✓ |
| 悬浮球 | 没有这个功能 | 退到别的 App 后浮在屏幕上 ✓ —— 要**单独授权**「显示在其他应用上层」✓（设置页里那一行勾上会拉你去 ✓） |

## 已知限制

- 走动是**移动整个窗口**实现的，所以不会被别的窗口遮住
- 没有爬墙 / 掉落物理，撞到屏幕边就折返
- 模型没有骨骼，是 722 个节点的刚体层级（对桌宠够用）
- **长期记忆没有语义向量**（DeepSeek 没 embeddings），检索靠字面匹配 ——
  换个完全不同的说法可能就找不着
- **记忆可能记岔**：错的条目会一直影响对话。怀疑她记错了就删 `%APPDATA%\...\桌宠\pet_memory.json`
- 「偷看屏幕」要后端模型支持视觉（名字里带 `vision`），所以**默认关着**
- 聊天 / 偷看 / 摄像头**共用一个气泡**，同一时刻只跑一条

## 名字

`Pet`（她住在桌面上）+ `Deek`（念着顺口）。中文里平时就叫她**桌宠** —— 那是类别词，不是项目名。

> ⚠️ 想改 `project.godot` 里 `config/name` 的话**先看那两行注释**：改错会让 `user://`
> 指向新目录，她的记忆 / 配置 / 密钥全部"失联"（项目用 `use_custom_user_dir` 钉住了）。
